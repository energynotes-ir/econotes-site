# EcoNotes · میز پژوهش اقتصاد و بازار

اکونوتس داشبورد فارسی‌زبان برای داده‌های اقتصاد کلان و بازار ایران است. سری‌های دارای تاریخچه واقعی را کنار تحلیل ریسک، همبستگی متحرک و آزمایش حساسیت قرار می‌دهد. نسخه فعلی را می‌توان به‌شکل سایت استاتیک با snapshot عمومی داده‌ها روی GitHub Pages منتشر کرد؛ SQL، Docker و به‌روزرسانی خودکار دائمی را می‌توان در مرحله بعد فعال کرد. راهنمای انتشار و اتصال دامنه در [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) است.

## راه‌اندازی محلی

پیش‌نیاز: Node.js 20.9+ و Python 3.11+.

```sh
npm ci
python3 -m venv .venv
source .venv/bin/activate
pip install -r api/requirements.txt
cp .env.example .env.local
npm run dev:all
```

سایت: `http://127.0.0.1:3000` · API: `http://127.0.0.1:8000/api/v1/health`. این فرمان برنامه، API و worker به‌روزرسانی خودکار را اجرا می‌کند. worker شاخص کل و هم‌وزن TSETMC را به‌روزرسانی می‌کند. برای به‌روزرسانی محلی، فرایندها و شبکه باید روشن بمانند؛ اجرای دائمی تولیدی به مدیر فرایند میزبان نیاز دارد.

## پوشش و تعریف داده

- **ارز آزاد:** قیمت پایانی روزانه بازار USDT/TMN والکس؛ منبع مستقل دیگری برای دلار آزاد در رابط منتشر نمی‌شود. آرشیو قدیمی نوبیتکس نگه داشته شده، اما worker آن را به‌روز نمی‌کند.
- **بورس:** شاخص کل و شاخص هم‌وزن TSETMC. پوشش انتخابی تعدادی از نمادها در رابط و API عمومی غیرفعال است تا پوشش سهام یکدست بماند. داده محلی قبلی نمادها از پایگاه پاک نشده است.
- **نرخ رسمی ارز:** نرخ‌های روزانه خرید/فروش ETS و سری‌های جداگانه ماهانه بانک مرکزی؛ ماهانه و روزانه با هم ترکیب نشده‌اند.
- **فلزات گران‌بها:** طلای ۱۸ عیار ایران و انس جهانی spot از TGJU. انس، fixing رسمی LBMA نیست.
- **تورم:** CPI خام ماهانه ایران و اجزایش، نرخ ماهانه و نقطه‌به‌نقطه منتشرشده، و CPI آمریکا از OECD.
- **پول و نرخ‌ها:** سری فصلی نقدینگی و پایه پولی از بانک مرکزی، با بازنشر MEFA برای فصل‌های جدیدتر تا زمستان ۱۴۰۴؛ OMO هفتگی و YTM زنده فرابورس. ماه‌های منتشرنشده درون‌یابی نمی‌شوند.
- **آرشیو اوراق خزانه:** قیمت روزهای دارای معاملهٔ اخزا و سخاب از TSETMC، برای نمادهای فعال و سررسیدشده. YTM هر نماد از قیمت معامله و تاریخ سررسید محاسبه می‌شود؛ میانگین تاریخی این آرشیو با YTM رسمی زندهٔ فرابورس یکی نیست.

آخرین مشاهده، منبع، تواتر، تعداد مشاهدات و زمان دریافت برای هر سری قابل بررسی است. زمان دریافت به معنی زمان انتشار آمار نیست. داده فرضی به سری منبع‌دار افزوده نمی‌شود. داده‌های فصلی و ماهانه می‌توانند روی محور روزانه به‌شکل پله‌ای دیده شوند، اما به‌عنوان مشاهدات روزانه جدید در همبستگی محاسبه نمی‌شوند.

## ابزارهای تحلیل

- نمودار سطح، انتخاب بازه، جابه‌جایی پنجره، بزرگ‌نمایی و دریافت CSV.
- همبستگی و همبستگی متحرک روی بازده‌های لگاریتمی مشترک؛ سطوح برای مقایسه به پایه ۱۰۰ تبدیل می‌شوند.
- دیدبان ریسک: انحراف معیار بازده، صدک تاریخی نوسان، فاصله از قله، بیشترین افت و صدک پنجم بازده گذشته.
- آزمایش سناریو: رگرسیون تک‌متغیره هم‌زمان، ضریب حساسیت، قدرت توضیح، دامنه خطای تاریخی و نمایش برون‌یابی بیرون از دامنه شوک.
- مقایسه عملکرد شاخص کل و هم‌وزن و دیدبان شخصی محلی در مرورگر.

این ابزارها روابط تاریخی را خلاصه می‌کنند؛ خروجی سناریو پیش‌بینی قطعی، رابطه علّی یا توصیه سرمایه‌گذاری نیست.

## اجرای سرور و بررسی کد

طرح مسئولیت و کنترل نقش‌های آینده در [docs/AGENT_WORKFLOWS.md](docs/AGENT_WORKFLOWS.md) ثبت شده است.

```sh
npm run lint
npm run typecheck
npm run build
```

برای ساخت و بررسی نسخه استاتیک محلی، ابتدا snapshot پایگاه داده را بسازید و بعد خروجی سایت را تولید کنید:

```sh
npm run prepare:static
```

فایل‌های قابل انتشار در `out/` قرار می‌گیرند. JSONهای `public/data/` snapshot عمومی و قابل مشاهده برای همه‌اند؛ تا زمانی که snapshot تازه ساخته و منتشر نشود، داده‌ها به‌روز نمی‌شوند. برای اجرای سرور با API و پایگاه داده در مرحله بعد از `docker compose up -d --build` استفاده کنید.

## وضعیت سرویس

ثبت‌نام، پرداخت و سطح دسترسی اشتراک هنوز پیاده‌سازی نشده‌اند. snapshot استاتیک برای همه عمومی است و کنترل اشتراک ندارد. دیدبان من در فضای ذخیره‌سازی همین مرورگر ثبت می‌شود. برای به‌روزرسانی snapshot، داده را در پایگاه محلی تازه‌سازی و workflow انتشار GitHub Pages را اجرا کنید. دسترسی اشتراک در نسخهٔ سروری آینده باید سمت API کنترل شود.
