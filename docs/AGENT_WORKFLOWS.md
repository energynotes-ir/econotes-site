# طرح نقش‌های پژوهشی EcoNotes

این سند تعریف نقش‌های آینده است. در نسخه فعلی، زمان‌بند Python واکشی منابع را اجرا می‌کند؛ عامل هوش مصنوعی فعال، انتشار خودکار تحلیل یا گردش‌کار نیازمند تأیید انسانی پیاده‌سازی نشده است.

| نقش | ورودی | خروجی بازبینی‌پذیر | اختیار انتشار |
| --- | --- | --- | --- |
| هماهنگ‌کننده پژوهش | درخواست، متغیرها و تواتر موردنیاز | فهرست کارها با شناسه، وابستگی و مالک | ندارد |
| پژوهشگر منبع | فهرست سری‌های بدون منبع یا منبع منقضی | آدرس و تعریف ناشر، نمونه پاسخ، تناوب، حق استفاده و ریسک پایداری | پیشنهاد منبع؛ بدون تغییر کاتالوگ |
| عامل اتصال داده | طرح مصوب منبع و قرارداد schema | adapter، لاگ واکشی و نتیجه اجرای قابل بازتولید | می‌تواند داده خام sandbox را بنویسد؛ انتشار پس از کنترل کیفیت |
| بازرس کیفیت داده | payload و تاریخچه سری | گزارش تازگی، تکرار، شکاف، واحد، نقاط پرت، تغییر schema و پوشش تاریخ | می‌تواند سری را quarantine کند؛ بازنویسی سری تأییدشده نیازمند بازبینی |
| اقتصادسنج | سری‌های تأییدشده و تعریف شاخص | فرمول نسخه‌دار، کد مشتق‌سازی، تست‌های عددی، پوشش و محدودیت آماری | ندارد |
| پژوهشگر بازار و ریسک | سری‌های منتشرشده و تقویم معتبر | افت بازار، تغییر رژیم، حساسیت، مقایسه صنعت و توضیح همراه شمار مشاهدات | فقط پیش‌نویس؛ انتشار نیازمند مدیر پژوهش |
| ویراستار پژوهش | خروجی نقش‌ها و فراداده منبع | خلاصه فارسی و یادداشت ریسک با پیوند به سری و روش | ندارد؛ بازبینی مدیر پیش از انتشار عمومی |
| ناظر عملیات | وضعیت worker، API و پایگاه داده | هشدار stale، شکست تکراری یا خطای schema با شواهد | هشدار می‌دهد؛ واکشی مجدد طبق سیاست از پیش تعیین‌شده |

## قرارداد تحویل تحلیل

هر خروجی ماشینی باید شناسه نسخه، زمان تولید، شناسه دقیق ورودی‌ها، شناسه منبع، تعریف و واحد سری، بازه تاریخی، تعداد مشاهدات، روش هم‌ترازی تواتر، فرمول و محدودیت‌های مهم را همراه داشته باشد. نتیجه‌ای که داده لازم یا مرجع بازبینی‌پذیر ندارد باید با وضعیت `insufficient_data` برگردد، نه با مقدار ساختگی.

## مرزبندی اجرا

- نقش‌ها از طریق قراردادهای محدود و خروجی ساختاریافته با هم کار کنند؛ دسترسی عمومی مرورگر را به worker یا پایگاه داده ندهید.
- عامل پژوهش منبع به‌تنهایی مجاز به دورزدن ورود، CAPTCHA، محدودیت API یا شرط مجوز استفاده نیست.
- هر منبع جدید ابتدا در sandbox اجرا و با تعداد نقاط، تاریخ آخر، واحد، منبع و fixture ثبت‌شده تأیید شود.
- agent نمی‌تواند روش شاخص یا مشاهده قبلی را بی‌ردپا عوض کند. اصلاح داده باید نسخه، مقدار پیشین و علت را ثبت کند.
- رویداد سیاسی، رژیم بازار و گزارش تحلیلی پیش از نمایش عمومی تأیید انسانی می‌خواهد.
- در نسخه‌ای که اشتراک دارد، مجوز کاربر باید در API ارزیابی شود؛ پنهان‌کردن اجزا فقط در React کنترل دسترسی نیست.
