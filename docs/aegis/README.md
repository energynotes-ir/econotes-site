# EcoNotes Aegis Workspace

This workspace records approved product requirements, implementation plans, architecture boundaries, and repository baselines for EcoNotes.

## Authority

- User-approved requirements and specifications define intended product behavior.
- Plans translate approved requirements into bounded engineering work; they do not replace user approval where a later gate is explicitly required.
- Baseline snapshots are dated repository evidence, not independent authority.
- Project instructions in AGENTS.md and current code contracts remain in force.
